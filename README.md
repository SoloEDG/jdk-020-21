## 分期施工

机坪布局固定，运营中可在「分期施工」面板按既定分期方案改造机位：

- **两种施工方式**：临时通道（先建绕行道路维持运行，工期长、成本高、绕远近）与整体封闭（直接截断道路，工期短、绕行与延误更大），二者都会真实改变车辆绕行里程、可接纳机型与航班预计延误。
- **预览与确认分离**：面板只显示预计影响（绕行米数、可达性、机型变化、预计延误、资源余量），保存方案仅排队；点击「确认施工」后才封闭区域并占用预算与物料。
- **安全约束**：停靠飞机或正在作业的车辆会阻止施工；已获准进入施工区的车辆沿可用道路安全驶离，未进入的调度基于当前已生效布局重新检查可达性，封闭隔离机位不可再分配或派遣。
- **机位身份保持**：机位移动或升级后 ID 不变，历史航班、保障任务与 `standHistory` 坐标轨迹仍能认出同一机位。
- **依赖与不可回滚**：后期阶段依赖前期完工；已投入的资源与已生效变更不会因后期失败而回滚，未施工的排队方案可无成本撤销。
- **存档续工**：存档版本升级至 v2（自动迁移 v1），保存重开后从实际施工阶段继续，地图、机位分配与车辆路线共用同一份已生效布局。
